## 정의

Domain Name System의 약자로 호스트의 도메인 네임을 네트워크 주로 변환하거나, 그 반대의 역할을 수행하는 시스템이다.

가령, 네이버를 접속하기 위해서 우리는 네이버의 IP 주소가 아닌 도메인 주소를 브라우저에 입력한다. 이 도메인 주소를 IP 주소로 변환하여 네이버에 접속하게 해주는 시스템이다.

## 작동 원리

세부적인 동작원리는 복잡하다. 네이버를 예시로 들어보자.

1. 웹 브라우저에 [`www.naver.com`](http://www.naver.com) 을 입력하면 PC에 저장된 Local DNS(기지국 DNS 서버)에게 먼저 `www.naver.com` 이라는 호스트네임에 대한 IP 주소를 요청한다.
    
    > Local DNS : 가입했던 각 통신사의 기지국 DNS 서버
    
2. Local DNS는 `www.naver.com` 의 IP 주소를 찾아내기 위해 다른 DNS서버들과 통신(DNS 쿼리)를 시작한다.
    
3. 먼저 Root DNS 서버에게 IP 주소를 요청한다.
    
    > Root DNS : 인터넷의 도메인 네임 시스템의 루트 존이다.
    
4. Root DNS 서버는 IP 주소를 찾을 수 없어, Local DNS 서버에게 다른 DNS 서버에게 물어보라고 응답을 한다.
    
5. Local DNS 서버는 com 도메인을 관리하는 TLD DNS 서버에 다시 IP 주소를 요청한다.
    
    > TLD DNS : 도메인 등록 기관이 관리하는 서버로, 도메인 네임의 가장 마지막 부분을 말한다. Authoritative DNS 서버 주소를 저장해두고 안내하는 역할을 한다.
    
6. com 도메인을 관리하는 DNS 서버에도 해당 정보가 없다면, Local DNS 서버에게 다른 DNS 서버에게 물어보라고 응답을 한다.
    
7. Local DNS 서버는 [naver.com](http://naver.com) DNS 서버(Authoritative DNS 서버)에게 IP 주소를 요청한다.
    
    > Authoritative DNS : 실제 개인 도메인과 IP 주소의 관계가 기록/저장/변경되는 서버이다. 일반적으로 도메인/호스팅 업체의 네임서버를 말하지만, 개인이나 회사 DNS 서버 구측을 한 경우에도 여기에 해당하게 된다.
    
8. [naver.com](http://naver.com) DNS 서버에는 IP 주소가 있기 때문에 Local DNS 서버에게 IP 주소를 응답한다.
    
9. 이를 수신한 Local DNS 서버는 naver.com의 IP 주소를 캐싱하고 이후 다른 요청이 있을시 응답할 수 있도록 IP 주소 정보를 PC에 전달해 준다.
    

이렇게 Local DNS 서버가 여러 DNS 서버에 차례대로 요청하여 IP를 찾는 과정을 재귀적 쿼리라고 한다.

## 서버 종류

### 기지국 DNS 서버

인터넷을 설치시 각각 통신사가 있고, 각각의 통신사마다 DNS 서버가 존재한다.

### Root DNS 서버

최상위 DNS 서버로 해당 DNS부터 시작해서 아래 딸린 node DNS 서버에게로 차례차례 물어보게 되는 구조로 짜여져 있다.

![image.png](/assets/images/posts/network/dns/dns-1.png)

### TLD 서버

Top-Level Domain의 약자로 최상위 도메인 서버이다. TLD는 국가명을 나타내는 국가최상위도메인과 일반적으로 사용되는 일반최상위도메인으로 구분된다.

![image.png](/assets/images/posts/network/dns/dns-2.png)

### Second-leve DNS 서버

TLD 서버에서는 Second-leve DNS 서버를 리턴해준다. TLD 서버에서 .com을 파악하고 그 앞에 달린 문자열을 보고 네이버 혹은 구글 서버에게 요청을 하는 것이다.

그렇게 요청받은 Second DNS 서버는 자체적으로 sub 도메인 서버로 넘기게 된다.

### Sub DNS 서버

www. dev. mail. cafe. 등을 구분하는 최하위 서버이다. naver 서버 안에서도 여러 서비스가 존재한다. 이 서비스들을 구분하는 도메인 네임이라고 보면 된다.
