## 정의

- 테이블 간 중복된 데이터를 허용하지 않는 것이 기본 목표
- 이를 통해 데이터베이스는 무결성 유지
- 또한, 데이터베이스의 저장 용량 확보

### 제 1정규화

- 테이블의 속성이 하나의 값만을 갖도록 분해
- 다음 규칙을 만족해야 함
    - 각 컬럼이 하나의 속성만을 가져야 함
    - 하나의 컬럼은 같은 종류나 타입의 값을 가져야 함
    - 각 컬럼은 유일한 이름을 가져야 함
    - 컬럼의 순서가 상관이 없어야 함

![](/assets/images/velog/eff20be6-8112-47a6-8150-fb260d06c328-image.png)

- 멘티들이라는 컬럼에는 여러 개의 값이 존재
- 해당 테이블에 제 1정규화를 적용하면 다음과 같음

![](/assets/images/velog/98d2fd3d-a36e-42be-b09e-4a7167f7e456-image.png)

### 제 2정규화

- 현재 테이블의 주제와 관련이 없는 컬럼을 다른 테이블로 빼는 작업
- 다음 규칙을 만족해야 함
    - 제 1정규화를 만족해야 함
    - 모든 컬럼이 부분적 종속이 없어야 함

![](/assets/images/velog/550f2ab1-f164-4045-a093-766ce51ac614-image.png)

- 테이블 분석은 다음과 같음
    - 교수이름과 교수주소는 교수ID에 완전 종속
    - 강의명은 강의코드에 완전 종속
    - 두 개의 완전 종속은 하나의 테이블로 표현할 이유가 없음
- 해당 테이블에 제 2정규화를 적용하면 다음과 같음

![](/assets/images/velog/65d7ff5d-c009-4335-b5f1-2253eade3905-image.png)

### 제 3정규화

- 테이블에 대해 이행적 종속을 없애도록 테이블을 분해

> 이행적 종속 : A → B이고 B → C이면 A → C가 성립되는 것

![](/assets/images/velog/f013a628-52ae-4782-89ad-2ac388b5b071-image.png)

- 김철수씨의 사정으로 2024.04.28 여행 담당 버스가 15나9561로 변경
- DB상에서 버스 번호가 변경됐으나 버스 기사는 박철수가 아닌 김철수
- 이런 경우 버스번호와 버스기사 모두를 변경해야하는 번거러움이 존재
- 해당 테이블에 제 3정규화를 적용한 테이블은 다음과 같음
