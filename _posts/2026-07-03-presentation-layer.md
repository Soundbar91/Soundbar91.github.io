## 정의

응용 계층에서 내려온 데이터를 서로 다른 컴퓨터에서 이해할 수 있는 형태로 변환하는 계층이다. 컴퓨터 마다 사용하는 문자 코드, 데이터 표현 방식, 암호화 방식, 압축 방식이 다를 수 있다. 이로 인해 데이터를 읽는 과정에서 문제가 발생할 가능성이 존재한다. 이를 방지하기 위해 표현 계층에서는 송신자와 수신자가 데이터를 올바르게 읽을 수 있도록 한다.

## 기능

### 데이터 형식 변환

서로 다른 시스템 사이에서 데이터 형식을 변환한다.

- 문자 코드 변환 : ASCII, UTF-8, EUC-KR
- 파일 형식 처리 : JPEG, PNG, MP3, MP4, PDF
- 데이터 구조 변환 : 객체, 배열, JSON, XML
- 바이트 순서 변환 : 빅 엔디언, 리틀 엔디언

### 인코딩과 디코딩

데이터를 전송 가능한 형태로 바꾸는 인코딩과 받은 데이터를 다시 원래 의미로 해석하는 디코딩을 담당한다.

### 암호화와 복호화

보안을 위해 송신 측에서는 데이터를 알아볼 수 없는 형태로 암호화하고 수신 측에서는 원래 데이터로 복호화한다.

### 압축과 압축 해제

송신 측에서는 데이터 크기를 줄이기 위해 압축하고 수신 측에서는 원래 데이터로 압축 해제한다. 이를 통해 네트워크 사용량을 줄이고 전송 속도를 높인다.

- ZIP : 여러 파일을 압축
- gzip : 웹 데이터 압축에 자주 사용
- JPEG : 이미지 압축
- MP3 : 오디오 압축
- MP4 : 영상 압축

### 직렬화와 역직렬화

프로그램 내부에 있는 객체나 배열의 경우 그대로 네트워크로 보낼 수 없다. 이를 JSON, XML 같은 형태로 바꿔저 전송하고 이 과정을 직렬화라고 한다. 반대로 JSON, XML 데이터를 다시 프로그램에서 사용할 수 있는 객체나 배열로 바꾸는 과정을 역직렬화라고 한다.
