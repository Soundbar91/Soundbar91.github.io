## 정의

사용자가 네트워크 서비스를 사용할 수 있도록 응용 프로그램과 네트워크 사이의 인터페이스를 제공하는 계층이다.

## 기능

### 네트워크 서비스 제공

사용자가 실제로 사용하는 네트워크 서비스를 제공한다.

- 웹 서비스 : HTTP, HTTPS
- 이메일 송신 : SMTP
- 이메일 수신 : POP3, IMAP
- 파일 전송 : FTP, SFTP
- 원격 접속 : Telnet, SSH
- 도메인 이름 조회 : DNS
- IP 주소 자동 할당 : DHCP

### 사용자 인터페이스와 네트워크 연결

사용자 요청을 네트워크 통신으로 바꾸는 역할을 한다.

### 데이터 요청과 응답 처리

클라이언트와 서버 사이에서 요청과 응답을 주고받는 방식을 정의한다.

### 응용 프로토콜 정의

서비스별로 어떤 규칙을 사용할지 정의한다.

## 관련 프로토콜

| HTTP   | 웹 페이지와 API 통신에 사용         |
| ------ | ------------------------- |
| HTTPS  | HTTP에 보안 통신을 더한 방식        |
| DNS    | 도메인 이름을 IP 주소로 변환         |
| SMTP   | 이메일 전송                    |
| POP3   | 이메일 다운로드 방식 수신            |
| IMAP   | 서버에 메일을 보관하며 동기화          |
| FTP    | 파일 전송                     |
| SFTP   | SSH 기반 보안 파일 전송           |
| SSH    | 원격 서버 접속                  |
| Telnet | 원격 접속, 현재는 보안상 거의 사용하지 않음 |
| DHCP   | IP 주소를 자동으로 할당            |
| SNMP   | 네트워크 장비 관리                |
| NTP    | 시간 동기화                    |
