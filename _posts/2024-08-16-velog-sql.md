## 정의

- 관계형 데이터베이스에 정보를 저장하고 처리하기 위한 프로그래밍 언어

## 종류

- DDL
    - 데이터베이스를 정의하는 명령어
    - 데이터베이스 관리 혹은 데이터베이스 설계자가 사용
        - create : 데이터베이스 및 테이블 생성
        - alter : 테이블 수정
        - drop : 데이터베이스 및 테이블 삭
- DML
    - 데이터베이스 테이블의 레코드를 조회, 수정 그리고 삭제하는 명령어
    - 데이터베이스 사용자와 데이터베이스 관리 시스템 간의 인터페이스 역할
        - insert : 데이터 삽입
        - select : 데이터 조회
        - update : 데이터 수정
        - delete : 데이터 삭제
- DCL
    - 데이터베이스에 대한 접근 권한 제어 및 트랜잭션 컨트롤하는 명령어
        - grant : 권한 부여
        - revoke : 권한 회수
        - commit : 완료된 작업으로 인한 데이터를 데이터베이스에 반영
        - rollback : 작업 시작 이전 상태로 복구

## Join

### 정의

- 두 개 이상의 테이블을 묶어서 데이터를 조회 및 수정할 때 사용

### 종류

- Inner join
    - 일반적인 join은 보통 Inner join 지칭
    - 테이블 간 데이터의 **교집합**
    ![](/assets/images/velog/20a2a4c5-f6f1-49f3-88df-ec528aaae7c2-image.png)

    
    - 상품의 이름을 관리하는 테이블과 상품의 수량을 관리하는 테이블
    - 이 두 개의 테이블은 상품코드라는 속성이 공통 속성
    
    ```sql
    SELECT N.상품코드 상품코드, N.상품명 상품명, C.수량 수량
    FROM TableA as N              // 첫 번째 테이블
    INNER JOIN TableB as C        // 두 번째 테이블
    ON N.상품코드 = C.상품코드     // 결합 조건
    ```
    
    - TableA의 상품코드와 TableB의 상품코드가 같은 레코드만 결합하도록 ON을 사용해서 조건을 작성
    - Inner join을 진행할 때, 두 테이블에 모두 지정한 열의 데이터가 있어야 함
    
    ![](/assets/images/velog/f8579d57-3b00-4ef9-9657-5bb98833c440-image.png)
    
- Outer join
    - 한 쪽에만 데이터가 있어도 결과가 나온다.
    - Outer join은 Left, Right 그리고 Full 3가지로 구분
    
    ```sql
    SELECT <열 목록>
    FROM <첫 번째 테이블(LEFT 테이블)>
        <LEFT | RIGHT | FULL> OUTER JOIN <두 번째 테이블(RIGHT 테이블)>
         ON <조인 조건>
    [WHERE 검색 조건]
    ```
    
    - Left join : 왼쪽 테이블의 모든 값이 출력
    
    ![](/assets/images/velog/aea6fd53-83c2-4b18-abdd-3a550ff030c4-image.png)
    
    - Right join : 오른쪽 테이블의 모든 값이 출력
    
    ![](/assets/images/velog/f66fedae-2747-4aa9-a0ce-60b52fefb23c-image.png)
    
    - Full join : 왼쪽 또는 오른쪽 테이블의 모든 값이 출력
    
    ![](/assets/images/velog/a10d8cf8-9ff5-499c-86d0-c64847b8608f-image.png)
