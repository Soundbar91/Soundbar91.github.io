## 정의

- Object-Oriented Programming, 객체 지향 프로그래밍
- 필요한 데이터를 추상화하여 **속성과 행위**를 가진 객체를 만들고, 그 객체들 간의 유기적인 상호작용을 통해 로직을 구성하는 프로그래밍 방법
- 현실 세계와 비슷하게 프로그래밍 코드를 속성과 행위를 가진 객체로 생성하고, 이렇게 생성된 객체끼리 서로 상호 작용을 하며 소프트웨어가 동작

## 특징

- 추상화
    - 객체들의 **공통 속성과 기능을 하나로 묶는 것**
    - 추상 클래스, 추상 메소드 그리고 인터페이스로 추상화를 표현
    ```java
    public interface Phone {
       void showInformation();
       void call(String phoneNumber);
       void sendMessage(String message, String phoneNumber);
       void powerOn();
       void powerOff();
    }
    ```
    
    - 휴대폰의 공통적인 기능인 전화 걸기, 메시지 보내기, 전원 켜기, 전원 끄기 그리고 휴대폰 정보 보여주기를 인터페이스 추상 메소드로 선언했다.
    - Phone 인터페이스를 상속받는 클래스들은 추상 메소드를 재정의함으로써 추상화를 표현할 수 있다.
    
    ```java
    
    public class Samsung implements Phone {
       private String phoneNumber;
       private String phoneName;
       private boolean power;
    
       public Samsung(String phoneNumber, String phoneName) {
           this.phoneNumber = phoneNumber;
           this.phoneName = phoneName;
       }
    
       @Override
       public void showInformation() {
           System.out.println("phoneNumber = " + phoneNumber);
           System.out.println("phoneName = " + phoneName);
       }
    
       @Override
       public void call(String phoneNumber) {
           if (this.power) System.out.println(phoneNumber + "에 전화를 겁니다.");
       }
    
       @Override
       public void sendMessage(String message, String phoneNumber) {
           if (this.power) {
               System.out.println("message = " + message);
               System.out.println(phoneNumber + "에 메세지를 보냅니다.");
           }
       }
    
       @Override
       public void powerOn() {
           if (!this.power) {
               this.power = true;
               System.out.println("전원을 킵니다.");
           }
       }
    
       @Override
       public void powerOff() {
           if (this.power) {
               this.power = false;
               System.out.println("전원을 끕니다.");
           }
       }
    }
    
    ```
    
    - Samsung 클래스가 Phone을 상속받고, 메소드를 재정의 함으로써 휴대폰의 기본 기능을 사용할 수 있다.
    
    ```java
    public static void main(String[] args) {
       Phone phone = new Samsung("010-1234-5678", "갤럭시 s24");
       phone.showInformation();
       phone.powerOn();
       phone.call("010-5678-1234");
       phone.powerOff();
    }
    ```
    
- 다형성
    - **상속을 통해 기능을 확장, 변경**하여 하나의 코드로 여러 형태의 객체로 재구성되는 것을 의미
    - 메소드 오버로딩과 메소드 오버라이딩으로 다형성을 표현
    ```java
    public class Soldier {
       public void sayInformation() {
           System.out.println("저는 군인입니다.");
       }
    }
    ```
    
    - Soldier 클래스의 sayInformation() 메소드는 “저는 군인입니다.”라는 문구를 출력한다.
    
    ```java
    public class Private extends Soldier {
       @Override
       public void sayInformation() {
           System.out.println("저는 이등병입니다.");
       }
    }
    
    public class Private1st extends Soldier {
       @Override
       public void sayInformation() {
           System.out.println("저는 일병입니다.");
       }
    }
    
    public class Corporal extends Soldier {
       @Override
       public void sayInformation() {
           System.out.println("저는 상병입니다.");
       }
    }
    
    public class Sergeant extends Soldier {
       @Override
       public void sayInformation() {
           System.out.println("저는 병장입니다.");
       }
    }
    ```
    
    - Soldier 클래스를 상속받은 클래스들은 sayInformation() 메소드를 오버라이딩 함으로써 계급에 맞는 문구를 출력할 수 있다.
- 상속
    - **객체가 다른 객체의 필드와 메서드를 받아 재사용하거나, 새로운 기능을 추가**함으로써 코드의 재사용성을 향상
    - extends 키워드를 사용하여 상속을 표현
    
    ```java
    public class SamsungPlus extends Samsung {
       public SamsungPlus(String phoneNumber, String phoneName) {
           super(phoneNumber, phoneName);
       }
    
       public void orderBixby(String order) {
           if (this.power) System.out.println("빅스비에게 " + order + " 명령을 내립니다.");
       }
    }
    ```
    
    - Samsung 클래스를 extends 키워드를 통해 상속받은 SamsungPlus 클래스이다.
    - super() 메소드를 사용하여 상속받은 클래스의 생성자는 상속받은 클래스의 생성사를 호출한다.
    - 상속받은 SamsungPlus 클래스는 기존 Samsung 클래스의 메소드를 사용할 수 있다.
    - 또한, 상속받은 클래스만의 속성과 필드를 추가하여 사용할 수 있다.
    
    ```java
    public static void main(String[] args) {
       SamsungPlus phone = new SamsungPlus("010-1234-5677", "갤럭시 s24+");
       phone.powerOn();
       phone.call("010-1234-5678");
       phone.orderBixby("음악 틀어줘");
    }
    ```
    
- 캡슐화
    - **클래스 안에 서로 연관있는 속성과 기능들을 하나의 캡슐**로 만드는 것
    - 데이터를 외부에서 함부로 접근하지 못하게 보호
    - 접근제어자와 getter/setter로 캡슐화를 표현
    ![](/assets/images/velog/99ea5318-1ee3-4ae7-aa05-5a3bcd8edcb9-image.png)
    - 접근 제어자의 종류는 다음과 같다.
        - private는 단어 뜻처럼 동일 클래스 내부에서만 사용할 수 있어 외부에서 접근이 불가능 하다.
        - default는 접근 제어자를 설정하지 않으면 사용되는 디폴트 값으로, 동일 패키지 내부에서만 접근할 수 있다.
        - protected는 동일 패키지 내부에서 접근할 수 있으며, 해당 접근자로 선언된 클래스를 상속받은 클래스에서도 접근할 수 있다.
        - public는 단어 뜻처럼 아무 곳에서 다 접근할 수 있다.
    
    ```java
    public class People {
       private int money;
       private String name;
       public String nickName;
    }
    ```
    
    - People 클래스의 속성이다.
    - money과 name은 외부에서 수정되면 안되기 때문에 private로 선언했다.
    - nickname의 경우 언제든지 변할 가능성이 있기 때문에 public로 선언했다.
    
    ```java
    People people = new People(1000, "김철수", "수철김");
    
    people.name = "홍길동"; // Error
    people.money = 1234; // Error
    people.nickName = "김박수"; // OK
    ```
    
    - private로 선언된 name과 money를 변경하는 코드를 작성하게 되면 에러가 발생한다.
    - public로 선언된 nickName의 경우 외부에서 접근이 가능하다.
    
    ```java
    public int getMoney() {
       return money;
    }
    
    public void setMoney(int money) {
       this.money = money;
    }
    
    public String getName() {
       return name;
    }
    
    public void setName(String name) {
       this.name = name;
    }
    ```
    
    - get** : **에 해당하는 변수의 값을 반환하는 함수 / 접근자라고 불린다.
    - set** : **에 해당하는 변수의 값을 설정하는 함수 / 설정자라고 불린다.
    - 클래스 내부에 해당 함수를 선언하여 private로 선언된 필드에 접근할 수 있다.
    - 그러나, 꼭 숨겨야하는 정보의 경우에는 setter를 선언하지 않는 것이 좋아 보인다.

## 장점

- 코드 재사용이 용이하다.
- 유지보수가 쉽다.

## 단점

- 처리 속도가 상대적으로 느리다.
- 설계 시 많은 시간과 노력이 필요하다.
