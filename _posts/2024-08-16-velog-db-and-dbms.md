# Database

## 정의

- 여러 사람들이 **공유**하며 사용할 수 있도록 **통합**해서 **저장**한 데이터의 집합

## 특징

- **실시간**으로 사용자의 데이터 요구에 응답
- 데이터의 지속적인 삽입, 삭제, 수정을 통해 **정확한 데이터**를 유지
- **동시**에 데이터가 공유되면서 사용
- **데이터 내용 기반**으로 참조

## 유형

- 관계형 데이터 베이스 : 열과 행이 있는 테이블 집합으로 구성
    - 대표적인 DBMS : 오라클 DBMS, 마이크로소프트 MS SQL Server, MySQL, PostgreSQL
- 객체 지향 데이터베이스 : 객체 형태로 정보가 표현
    - 대표적인 DBMS : Object Store, UniSQL
- NoSQL 데이터베이스 : 관계형 데이터베이스와 다른 형태로 정보를 저장
    - 대표적인 DBMS : Redis, Apache Cassandra, MongoDB

# DBMS

## 정의

- 데이터베이스와 사용자 혹은 응용프로그램 사이에서 인터페이스 역할을 하는 프로그램
- 사용자 혹은 응용프로그램이 데이터베이스에 접근하여 데이터를 조작할 수 있도록 지원

## 장점

- 데이터베이스 감독 및 제어가 용이하여 성능 **모니터링, 백업, 복구** 같은 다양한 관리 작업이 가능
- 계정 관리 및 접근 권한을 설정할 수 있어, **권한이 없는 사용자는 접근을 하지 못하도록 막음**
- 데이터의 일관성과 무결성을 유지
- 사용자들이 같은 데이터를 공유

# RDMBS

## 정의

- 데이터가 열과 행으로 구성된 **테이블**에 저장되고, 테이블 간의 **관계**를 이용하여 데이터를 조작하는 데이터베이스 관리 시스템

## 테이블

- 테이블의 열에는 데이터의 속성, 행에는 속성에 대응되는 데이터의 값이 저장
    - 각 행에 대해 **레코드**라고 지칭
    - 각 열에 대해 **필드 혹은 속성**으로 지칭

## 장점

- 데이터의 일관성과 무결성을 보장
- SQL를 이용하여 데이터를 빠르게 처리

## 단점

- 복잡한 데이터 구조를 처리하게 되면 SQL 구문이 길어지고 처리 속도가 느려짐
- Scale-up만 지원하기 때문에 성능 향상을 위한 비용이 기하급수적으로 늘어남

> Scale-up : 성능 향상을 위해 기존의 부품 혹은 서버를 고성능의 부품과 서버로 교환하는 방법
