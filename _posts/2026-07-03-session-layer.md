## 정의

프로그람 간 세션을 설정, 관리 그리고 종료하는 계층이다. 여기서 세션이란 두 시스템 사이에서 일정 시간 동안 유지되는 통신 관계를 말한다.

전송 계층에서는 두 시스템 간의 데이터를 신뢰성 있게 전달하는 데 초점을 둔다면, 세션 계층에서는 애플리케이션 간의 대화 상태 관리에 초점을 둔다.

## 기능

### **세션 설정, 유지, 종료**

세션 계층은 통신을 시작할 때 세션을 만들고, 통신 중에는 세션이 유지되도록 관리하며, 통신이 끝나면 세션을 종료한다.

### 대화 제어

양쪽 시스템이 데이터를 어떤 방식으로 주고받을지 제어한다. 크게 3가지 방법이 존재한다.

- 단방향 : 한쪽에서만 데이터를 전송
- 반이중 : 양쪽이 데이터를 주고받을 수 있지만 동시에 전송은 불가능
- 양방향 : 양쪽이 동시에 데이터를 주고받을 수 있음

### 동기화

긴 데이터 전송 중간에 체크포인트를 설정할 수 있다. 만약, 통신 중 오류가 발생했을 때 처음부터 다시 전송한다면 네트워크 비용이 발생할 것이다. 이를 방지하기 위해 체크포인트 시점부터 다시 통신을 시작한다.

### 세션 복구

통신 도중 문제가 생기면 세션을 복구하거나 재연결하는 역할을 한다.

## 관련 프로토콜

- NetBIOS : 로컬 네트워크에서 세션 서비스를 제공
- RPC : 원격 시스템의 함수를 호출하는 방식
- PPTP : 터널링 연결에서 세션 개념 사용
- SMB : 파일 공유 과정에서 세션을 사용
- TLS/SSL 세션 : 보안 통신에서 세션 상태 유지
